💧 AquaPulse
A modern, full-featured hydration tracking application built natively for Android, designed to provide a seamless and integrated user exper
ience.

✨ Features
• Material You (Dynamic Color): Fully adapts its color palette dynamically based on the user's system wallpaper and theme, ensuring a native and harmonious look.

• Smart System Notifications: Features automated background push notifications ("Stay Hydrated!") triggered at customizable reminder intervals to keep users energized and on track.

• Interactive Home Screen Widgets:

  • Quick Add Widget: Displays current daily progress with quick-action buttons to log standard water amounts instantly.

  • Weekly Tracker Widget: Provides a visual bar-chart summary of the last 7 days of hydration history directly on the home screen.

• Quick Settings Tile Integration: Includes a custom Quick Settings Tile ("Log 200ml") in the Android notification panel for convenient, system-wide logging without opening the app.

• Comprehensive Dashboard & Logs: Offers an elegant circular progress indicator, customizable hydration goals, and detailed daily log histories.
